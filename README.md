# Python-Fundamentals

A complete Python tutorial built as a series of six Jupyter notebooks, covering everything from the absolute basics to object-oriented programming and file handling.

## Notebooks

| Part | Topics |
|------|--------|
| [Part 1](NoteBook/Python%20Fundamentals%20Part_1.ipynb) | Getting started, variables, data types, input/output, operators |
| [Part 2](NoteBook/Python%20Fundamentals%20Part_2.ipynb) | Conditional statements, loops, functions |
| [Part 3](NoteBook/Python%20Fundamentals%20Part_3.ipynb) | Strings, lists, tuples, dictionaries, sets |
| [Part 4](NoteBook/Python%20Fundamentals%20Part_4.ipynb) | Object-Oriented Programming |
| [Part 5](NoteBook/Python%20Fundamentals%20Part_5.ipynb) | File I/O, exception handling, list comprehensions, JSON module |
| [Part 6](NoteBook/Python%20Fundamentals%20Part_6.ipynb) | Modules, variable scope, regex, datetime, random, CSV, decorators, custom exceptions |

## Usage

Open any notebook in Jupyter Notebook or JupyterLab and run the cells in order.
